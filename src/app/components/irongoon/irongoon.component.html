What you need

Severed Chains

Severed Chains is the native PC port that makes all of the mods for Legend of Dragoon possible.

Follow the instructions in the setup guide.

Irongoon

Irongoon is the mod that receives the config file generated above to customize the Iroongoon ruleset.

Unzip the contents from the latest release of the mod 'as is' into the Severed Chain's /mods folder.

Then, open the /mods/irongoon/config.yaml file and paste in the copied contents of the generated config above.

FAQ

What can it do now?

The Irongoon mod is currently a glorified character and enemy stat randomizer.

What is next?

When more modding APIs become available, the rest of the Irongoon ruleset will be added.

I died...? I am stuck?

Irongoon aims to be a challenge run where if you game over your playthrough ends. You will need to play skillfully.

Not all seeds will be completable.
