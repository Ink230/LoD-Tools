What you need

Severed Chains

Severed Chains is the native PC port that makes all of the mods for Legend of Dragoon possible.

This builder targets Irongoon main.future (v0.5.1 package) with Severed Chains main.spike-testing. Use the matching engine from the Future bundle; an official development update can replace it with an incompatible build. Follow the setup guide for disc images and general setup.

Irongoon

Irongoon is the mod that receives the config file generated above to customize the Irongoon ruleset.

Download a matching platform bundle from Latest Irongoon Future and extract it into a new directory. Irongoon is already installed; supply your own disc images in isos and use launch.bat on Windows or launch on Linux/macOS. For a mod-only installation, back up your configuration, remove the old Irongoon JAR, and extract the mod ZIP into the matching engine's mods directory.

Save the generated YAML as mods/irongoon/configs/custom-ig.yaml. In Irongoon's in-game configuration menu, choose Rescan Profiles, select it under Load YAML Profile, then choose Use settings. New campaigns apply staged settings when they start; existing campaigns require saving and reloading. The builder's starting values are a custom preset, not the built-in Irongoon (Blueprint) defaults.

FAQ

What can it do now?

Irongoon provides configurable character, Dragoon, monster, Addition, Dragoon spell, party, encounter, shop, and inventory randomization.

Why did editing my YAML file not change my campaign?

Campaign saves contain an Irongoon configuration snapshot. Load the updated YAML profile and choose Use settings, then save and reload the campaign. mods/irongoon/config.yaml is a legacy fallback and migration source; it is not reread over an existing campaign snapshot. New-campaign-only options such as enabling all characters or Dragoons still require a new campaign.

How do Severed Chains presets relate to YAML profiles?

SC includes a read-only Irongoon (Blueprint) preset. Select it and use SC's Add action to create an editable copy. Edit Irongoon settings, choose Use settings, then return to SC's preset editor and confirm its save prompt. Active Configuration identifies the SC preset and shows (Modified) when settings differ. Loading YAML stages configuration separately; Use settings does not write a YAML file. Use Save YAML Profile or Save YAML As... for explicit file saves.

What is next?

When more modding APIs become available, the rest of the Irongoon ruleset will be added.

I died...? I am stuck?

Irongoon aims to be a challenge run where if you game over your playthrough ends. You will need to play skillfully.

Not all seeds will be completable.
