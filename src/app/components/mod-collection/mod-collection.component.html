Download and install mods

  1. Tick the green checkbox on each mod you want. Selections remain when you search, change filters, or finish a download. Use × to clear all selections.
  2. Click Download Mods. Your browser downloads the selected release packages, unpacks their ZIPs, and combines their contents into dragoonmods-mods.zip. JAR files stay intact. The spinner stays visible until it is ready.
  3. Close Severed Chains. Open its mods folder, creating that folder if needed.
  4. Move the downloaded ZIP into SC/mods and choose Extract Here. If your extractor only offers Extract All…, set the destination to the existing SC/mods folder. Do not create a dragoonmods-mods subfolder.
  5. Check that the mod JARs and their companion folders are directly inside SC/mods. For example: SC/mods/irongoon-v0.4.18.jar and SC/mods/irongoon/config.yaml. You can then remove the downloaded ZIP.
  6. Remove older JAR versions of the same mods before starting SC. Back up existing mod configuration before replacing files, and follow each mod’s setup guide.

Downloads use each mod’s primary release shown on its card. Irongoon uses its RB3 release; its special SC build must be installed separately. Greyed-out checkboxes have no combined download. Standalone tools are installed separately.

This combines files; it does not check whether selected mods work together. If files conflict or a download fails, no partial ZIP is saved. Your selections remain so you can retry.
